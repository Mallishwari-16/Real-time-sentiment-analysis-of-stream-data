# Real-time-sentiment-analysis-of-stream-data
Develop a real-time sentiment analysis system that processes continuous streaming text data (e.g., social media, news, or user reviews) using big data technologies.

This project is a fully functional **real-time sentiment analysis system** that processes **live streaming tweets** using Big Data technologies such as **Apache Kafka**, **Apache Spark Streaming**, and **Machine Learning (Naïve Bayes)** and **Deep Learning (BERT)** models. It includes **sarcasm detection** and a **Streamlit dashboard** for real-time visualization.

## 📌 Objective

To build a scalable and accurate real-time sentiment analysis pipeline that can classify the sentiment of live tweets while handling big data challenges like latency, volume, and velocity. The system also aims to enhance sentiment analysis with **sarcasm detection** and **dashboard visualizations**.

---

## 🛠️ Tech Stack & Tools

- **Data Streaming**: Apache Kafka
- **Processing Engine**: Apache Spark Streaming
- **Machine Learning**: Naïve Bayes (Scikit-learn)
- **Deep Learning**: BERT (Hugging Face Transformers)
- **Visualization**: Streamlit Dashboard
- **Sarcasm Detection**: Rule-based heuristic
- **Deployment Ready**: `.pkl` model, modular structure, and GitHub hosted

## 🚀 Features

- 🔄 **Live Tweet Ingestion** using Tweepy + Kafka

- 🧠 **Sentiment Classification**: ML (Naïve Bayes) and DL (BERT)
- 🐍 **Sarcasm Detection**: Keyword and emoji-based
- 📊 **Real-Time Visualization** using Streamlit
- 📈 **Performance Evaluation**: Accuracy, Precision, Recall, F1 Score
- 🧪 **Model Comparison**: ML vs DL performance
